## Sobre o Projeto

Este projeto consiste em uma **Landing Page de Portfólio Profissional**, desenvolvida como entrega da **Fase 1 - Projeto 1 do programa trendsIT**. O objetivo principal é estabelecer uma identidade digital profissional para apresentar minha trajetória, habilidades técnicas em desenvolvimento Back-End, pipelines de dados e sistemas RAG (Retrieval-Augmented Generation).

### Link da Aplicação (Deploy)
* **Live Preview:** *https://patriciastarck.github.io/repositorio-trendsit/*

---

## Funcionalidades e Requisitos Atendidos

* **Estrutura Semântica:** Construído integralmente com tags semânticas do HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) para garantir acessibilidade e SEO básico.
* **Design Responsivo (Mobile-First):** Layout adaptado para dispositivos móveis (a partir de 360px) até telas de desktop (1280px+), utilizando Flexbox e CSS Grid sem dependências de frameworks externos.
* **Vitrine de Projetos:** Galeria em cards apresentando aplicações desenvolvidas, tecnologias utilizadas e links diretos para os repositórios no GitHub.
* **Canal de Contato:** Formulário funcional integrado via `mailto:` e links diretos para redes profissionais (GitHub e LinkedIn).

---

## Tecnologias Utilizadas

* **HTML5:** Marcação semântica e estrutural.
* **CSS3 Puro:** Estilização customizada com variáveis CSS, Flexbox, CSS Grid e Media Queries.
* **Git & GitHub:** Versionamento de código e hospedagem.
